Контекстный помощник для написания текстов на английском языке. En-IntelliSense определяет намерение автора по всему черновику, дополняет слова, фразы и предложения, находит проблемы в тексте и предлагает точечные исправления.

Документация: [English](README.md) | [简体中文](README.zh-CN.md) | [Español](README.es.md) | [日本語](README.ja.md) | **Русский**

## Возможности

- Локальное дополнение слов и дополнение фраз или предложений с помощью языковой модели.
- Определение замысла по всему черновику и использование контекста в следующих подсказках.
- Автоматическая проверка грамматики, ясности, словоупотребления, повторов и тона.
- Точное выделение исходного фрагмента, объяснение проблемы и замена одним нажатием.
- Улучшение темы и выбранного текста, перевод, объяснение и упрощение выражений.
- Полезные фразы заменяют выделение или текущее предложение, а не добавляются в конец.
- Готовые документы сохраняются локально и могут быть открыты как редактируемые копии.
- Готовое письмо можно открыть в QQ Mail, 163 Mail, Gmail или другом веб-интерфейсе с заполненными адресатом, темой и текстом.

## Модель ИИ, стоимость и конфиденциальность

En-IntelliSense не содержит языковую модель, общий API-ключ или бесплатную квоту ИИ. Для модельного дополнения, проверки, улучшения текста и чата каждый пользователь настраивает собственного OpenAI-совместимого провайдера. Стоимость, ограничения, хранение данных и условия конфиденциальности определяются выбранным провайдером. Проект не предоставляет и не рекомендует неофициальные сервисы-посредники.

Без API-ключа доступны локальное дополнение слов, черновики, завершённые документы и передача письма. Функции ИИ остаются отключёнными, а интерфейс показывает `Add API key for AI`.

В этой архитектуре изоляция пользователей обеспечивается локальным хранилищем браузера, а не серверными учетными записями. Черновики хранятся только в `localStorage`; серверной базы черновиков нет. Функции ИИ отправляют необходимый текст провайдеру, выбранному пользователем. `.env` является локальным текстовым файлом: не добавляйте его в Git, не публикуйте ключ в GitHub Issue и ознакомьтесь с условиями провайдера перед обработкой конфиденциальных данных.

## Настройка и запуск

Скопируйте `.env.example` в `.env` и укажите данные собственного провайдера:

```dotenv
OPENAI_API_KEY=your_own_api_key
OPENAI_BASE_URL=https://api.openai.com
OPENAI_MODEL=gpt-4.1-mini
OPENAI_AUTOCOMPLETE_MODEL=gpt-4.1-mini
OPENAI_API_STYLE=chat
```

Используйте названия моделей, которые поддерживает выбранный провайдер.

```powershell
python -m pip install -r requirements.txt
python server.py
```

Откройте `http://127.0.0.1:8000`. Не добавляйте `.env` в Git и не размещайте API-ключ во фронтенд-коде.

## Приложение для Windows

Для обычного использования скачайте `En-IntelliSense.exe` из [последнего выпуска](https://github.com/ETOLucy/En-IntelliSense/releases/latest) и запустите двойным щелчком — команды не нужны. Текущая версия `v1.0.1` не подписана и может быть заблокирована Windows Smart App Control. Проект подал заявку в SignPath Foundation и после одобрения будет публиковать подписанные версии.

`powershell -ExecutionPolicy Bypass -File .\scripts\build_windows.ps1` требуется только разработчикам после изменения исходного кода. EXE не содержит API-ключей, модели или личных ресурсов сопровождающего. Переименуйте `En-IntelliSense.env.example` в `.env`, добавьте настройки собственного провайдера и перезапустите приложение.

## Развертывание в Cloudflare

По умолчанию используется Cloudflare Workers AI, поэтому для бесплатного развертывания внешний API-ключ не нужен. Секреты требуются только для подключения совместимого с OpenAI провайдера.

```powershell
npx wrangler login
npx wrangler deploy

# Необязательный внешний провайдер
npx wrangler secret put OPENAI_API_KEY
npx wrangler secret put OPENAI_BASE_URL
```

## Развертывание в EdgeOne Pages

Импортируйте репозиторий в EdgeOne Pages, выберите `main` как производственную ветку и оставьте команду сборки пустой. Файл `edgeone.json` публикует `public/` и развертывает функции из `node-functions/`.
