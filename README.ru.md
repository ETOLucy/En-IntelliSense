Контекстный помощник для написания текстов на английском языке. En-IntelliSense определяет намерение автора по всему черновику, дополняет слова, фразы и предложения, находит проблемы в тексте и предлагает точечные исправления.

Документация: [English](README.md) | [简体中文](README.zh-CN.md) | [Español](README.es.md) | [日本語](README.ja.md) | **Русский**

## Возможности

- Локальное дополнение слов и дополнение фраз или предложений с помощью языковой модели.
- Определение замысла по всему черновику и использование контекста в следующих подсказках.
- Автоматическая проверка грамматики, ясности, словоупотребления, повторов и тона.
- Точное выделение исходного фрагмента, объяснение проблемы и замена одним нажатием.
- Улучшение темы и выбранного текста, перевод, объяснение и упрощение выражений.
- Полезные фразы заменяют выделение или текущее предложение, а не добавляются в конец.
- Готовые документы сохраняются локально и могут быть открыты как редактируемые копии.
- Готовое письмо можно открыть в QQ Mail, 163 Mail, Gmail или другом веб-интерфейсе с заполненными адресатом, темой и текстом.

## Модель, квота и конфиденциальность демо

Сейчас публичное демо использует Cloudflare Workers AI с моделью `@cf/meta/llama-3.1-8b-instruct-fp8`. Текущая бесплатная квота составляет [10 000 Neurons в день](https://developers.cloudflare.com/workers-ai/platform/pricing/), сбрасывается в `00:00 UTC` и делится между всеми посетителями демо и другими приложениями Workers AI в той же учетной записи. Используйте общие функции ИИ умеренно и не запускайте Review, Polish или Chat повторно для неизмененного текста.

В этой архитектуре изоляция пользователей обеспечивается локальным хранилищем браузера, а не серверными учетными записями. Черновики хранятся только в `localStorage`; серверной базы черновиков нет. Данные изолированы между устройствами, браузерами и профилями, однако пользователи одного профиля браузера используют общее локальное хранилище. Функции ИИ отправляют необходимый текст настроенному провайдеру, поэтому не вводите конфиденциальную информацию в публичном демо.

## Настройка и запуск

Скопируйте `.env.example` в `.env` и задайте `OPENAI_API_KEY`. При необходимости настройте `OPENAI_MODEL`, `OPENAI_AUTOCOMPLETE_MODEL` и `OPENAI_BASE_URL`.

```powershell
python -m pip install -r requirements.txt
python server.py
```

Откройте `http://127.0.0.1:8000`. Не добавляйте `.env` в Git и не размещайте API-ключ во фронтенд-коде.

## Развертывание в Cloudflare

По умолчанию используется Cloudflare Workers AI, поэтому для бесплатного развертывания внешний API-ключ не нужен. Секреты требуются только для подключения совместимого с OpenAI провайдера.

```powershell
npx wrangler login
npx wrangler deploy

# Необязательный внешний провайдер
npx wrangler secret put OPENAI_API_KEY
npx wrangler secret put OPENAI_BASE_URL
```

## Развертывание в EdgeOne Pages

Предустановленный домен EdgeOne требует временную подписанную ссылку с параметрами `eo_token` и `eo_time`; адрес `.edgeone.cool` без них возвращает `401 Authorization Required`. Для стабильного публичного адреса добавьте собственный поддомен в **EdgeOne Pages > Settings > Custom Domains**, настройте предложенную CNAME-запись и дождитесь статуса `Pass`. Не публикуйте и не добавляйте в Git временные подписанные ссылки. Для ускорения в материковом Китае собственному домену требуется регистрация ICP.
