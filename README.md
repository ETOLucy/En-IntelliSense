# EnWrite

EnWrite is a focused email-writing workspace for English learners. It provides code-editor-style inline continuations, adaptable language levels, useful phrase prompts, and lightweight writing feedback without taking over the author's voice.

## Run

Open `index.html` in a modern browser. No build step or dependencies are required.

## Interactions

- Type in the letter editor to receive a contextual continuation.
- Press `Tab` to accept a suggestion or `Esc` to dismiss it.
- Switch between Simple, Natural, and Advanced English.
- Click useful phrases to insert them at the cursor.
- Draft text is saved locally in the browser.
