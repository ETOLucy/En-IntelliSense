# EnWrite

EnWrite is a focused browser-based writing workspace for English learners. It supports letters, essays, and casual messages with code-editor-style inline continuations, adaptable language levels, contextual phrase prompts, lightweight feedback, local draft saving, and a shareable referral link.

## Run

Open `index.html` in a modern browser. No build step or dependencies are required.

## Interactions

- Choose Letter, Essay, or Message and type to receive a contextual phrase or sentence continuation.
- Press `Tab` to accept a suggestion or `Esc` to dismiss it.
- Switch between Simple, Natural, and Advanced English.
- Click useful phrases to insert them at the cursor.
- Draft text is saved locally in the browser.
- Use Share or Copy invite link to recommend the tool.
