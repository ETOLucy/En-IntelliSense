- 画面比例：16:9，1920 x 1080
- 配音方式：将下方“连续配音稿”导入必剪 AI 人声
- 推荐语速：正常或 `0.95x`，不要使用过于活泼的角色音

## 连续配音稿

由于主包英语不太好，和外国笔友聊天、写邮件时总是很头疼。

主包突然想到：代码可以自动补全，英语为什么不行？

于是，主包做了 WriteMelo，一个像代码补全一样的英文写作软件。

它会结合前文，补全单词、短语，甚至整个句子。

写完以后，还能找出不自然的表达，用中文解释原因，并一键修改。

润色、简化和写邮件也能完成。草稿保存在本地，AI 模型由你选择。

由于主包比较懒，第一版走朴素实用路线，需要自备 AI 模型，目前更适合熟悉 API 的程序员朋友。

后续会继续降低门槛，面向普通英语学习者，增加更多实用功能。

WriteMelo 已提交 Windows 应用商店，正在审核，等待上架。现在也能前往 GitHub 免费下载，欢迎体验。
