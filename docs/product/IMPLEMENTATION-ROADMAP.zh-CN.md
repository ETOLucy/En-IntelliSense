# 实现路线

## 2.0 beta：本地写作工作台

- CodeMirror 工作台、中英文界面、本地文档与响应式检查器。
- 词汇、常用表达、专有名词、缩写和产品名的本地补全。
- 离线拼写、确定性诊断、快速修复、大纲、检查清单、版本历史和个人词典。
- 正文 lint 标记、悬浮解释、边缘问题位置、Quick Fix 和问题面板到正文定位。
- 词级版本 Diff、预览、恢复确认、撤销、快照去重和保留上限。
- 文档重命名；真正打开/保存 `.txt`、`.text`、`.md`、`.markdown`；导入 `.txt` 和 Hunspell `.dic` 词典。
- 容错候选，以及可用 Tab/Escape 控制的固定表达续写。
- 关闭、仅问题、问题加全文三种明确 AI 同意模式。
- 安全 Electron 容器、Windows 安装包/便携版与自动化测试。

## 2.1：学习型智能

- 本地搭配索引和按学习等级排序的词汇。
- 将主动补全词汇扩展到当前 61 个排序词和 7 个固定片段之外。
- 建立真正影响补全排序的本地使用历史闭环。
- 用精确率与回归测试扩展术语一致性和语法规则覆盖。
- 用户自定义可复用片段，以及更多经过明确验证的文件格式。
- 无障碍与键盘操作审查。

## 2.2：托管 beta

- 把登录与 Session 迁移到 TypeScript。
- 使用预留与释放的统一额度账本。
- 区域模型池、自动故障转移和成本控制。
- 提供少量免费托管 AI 试用，单位透明，不假设供应商免费额度永远存在。

## 后续入口

Chrome、Google Docs 和 Word 复用 contracts 与 writing-core。它们是独立交付入口，不能反过来把核心绑定到 Electron 或 React。
