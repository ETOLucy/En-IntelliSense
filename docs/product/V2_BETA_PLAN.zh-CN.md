# WriteMelo 2.0 Beta 规划

> 更新日期：2026-07-29。税务、支付、商店和模型供应商规则会变化。本文是工程与产品规划，不构成法律、税务或会计意见。

## 目标用户

首批 Beta 面向：

- 普通英语学习者；
- 大学生；
- 已成年的四六级、考研、雅思、托福等考试用户。

首批 Beta 不主动面向未成年人。不满 14 周岁用户涉及儿童个人信息的特殊保护要求；在年龄方案、监护人同意、儿童隐私说明、数据最小化和删除流程完成前，不开放对应注册与收费。

## 版本目标

让不熟悉 API 的学习者完成以下流程：

1. 使用邮箱验证码登录；
2. 获得少量 Beta 托管额度；
3. 无需看到模型 Key 即可完成补全和检查；
4. 查看自己的额度和工单；
5. 自愿开启云端学习记录；
6. 随时导出或删除账号数据。

高级用户继续保留“自备模型服务”模式。自备 Key 仅由 Windows DPAPI 保存在本机，不上传到云端。

## 模型供应商边界

托管模型 Key 只保存在 Cloudflare Worker Secret 中，不下发到客户端，也不参与云同步。

### 零成本 Beta 路线

02 默认通过 Workers AI Binding 调用基础体验模型，不需要把维护者 API Key 放进客户端。Cloudflare 官方文档截至 2026-07-08 说明：Workers Free 每日包含 10,000 Neurons，免费计划超过该分配后需要主动升级到 Workers Paid，不能直接产生超额用量费用。

- 本项目保持 Workers Free，不启用自动付费升级；
- 每个用户仍受月度使用单位、每分钟请求数和设备数限制；
- 全站免费资源池耗尽时直接停止托管调用，并提示稍后再试或使用 Windows 本地自备 Key；
- 免费体验模型只用于验证工作流，不承诺固定可用性、固定模型或与高质量商业模型相同的效果；
- 管理员明确配置外部供应商 Secret 后，才允许切换到其他托管线路。

官方依据：

- Workers AI 定价：https://developers.cloudflare.com/workers-ai/platform/pricing/
- Workers AI Binding：https://developers.cloudflare.com/workers-ai/configuration/bindings/

在选定供应商前，不接入来源不明的“中转站 Key”。生产供应商必须至少提供：

- 明确允许把模型能力集成到付费终端产品的条款或书面授权；
- 合法经营和收款主体；
- 发票或合规结算凭证；
- 数据处理、日志保留、训练使用和跨境说明；
- 可用性、限流和封禁处理机制；
- 密钥轮换与事件响应渠道。

购买普通个人 Key 后再次分装、共享或转售，不视为已经获得商业转售权。

## 收费决策

2.0 Beta 暂不收费，只提供严格限制的测试额度。原因：

- 登录、隔离、额度和模型成本尚未经过真实流量验证；
- 经营主体、开票和纳税方式尚未确定；
- 模型供应商的商业封装权尚未核实；
- 支付会引入退款、拒付、权益恢复和客服责任；
- Microsoft Store 重新审核需要可测试的登录账号和稳定服务。

正式收费前，优先比较：

1. Microsoft Store 应用内购买或周期性订阅；
2. 具有合法商户入驻能力的安全第三方支付平台。

Microsoft Store 当前政策允许 PC 上的非游戏产品使用 Microsoft Store 应用内购买，或安全的第三方购买 API；第三方支付需要在 Partner Center 申报，并满足身份确认、交易确认和支付安全要求。

不要自行收集银行卡信息。

## 税务边界

不存在“收入低于某个统一金额就完全不用缴税”的规则。

截至本文日期：

- 财政部、税务总局公告 2023 年第 19 号规定：月销售额 10 万元以下（含本数）的增值税小规模纳税人免征增值税，执行至 2027 年 12 月 31 日。
- 该 10 万元门槛只针对符合条件的小规模纳税人的增值税，不等于免个人所得税、经营所得税，也不等于无需登记、申报或开票。
- 财政部、税务总局公告 2023 年第 12 号规定：2023 年 1 月 1 日至 2027 年 12 月 31 日，个体工商户年应纳税所得额不超过 200 万元的部分，减半征收个人所得税。这里是“减半征收”，不是免税；“应纳税所得额”也不是营业收入。

正式收费前需要：

1. 向所在地市场监管部门确认采用个体工商户还是公司主体；
2. 携业务模式和预计流水咨询当地 12366；
3. 确认支付平台、Microsoft Partner Center 的主体与结算资料；
4. 确认发票、申报周期、成本凭证和退款处理；
5. 不使用私人收款码长期经营订阅服务。

官方参考：

- 增值税小规模纳税人减免政策：<https://fgk.chinatax.gov.cn/zcfgk/c102416/c5210457/content.html>
- 小微企业和个体工商户税费政策：<https://www.gov.cn/zhengce/zhengceku/202308/content_6896379.htm>
- Microsoft Store 财务交易政策：<https://learn.microsoft.com/en-us/windows/apps/publish/store-policies#108-financial-transactions>

## 数据与隔离

服务端身份只从已验证会话中取得。客户端提交的 `user_id` 不用于授权。

必须按用户隔离：

- 会话；
- 权益和额度；
- 工单；
- 云文档；
- 修改记录；
- 收藏表达；
- 支付事件。

管理员默认不能查看用户草稿和学习正文。客服只能查看用户主动写入工单的内容。

云同步采用显式开启：

- 默认继续本地保存；
- 首次开启前说明同步哪些字段；
- 支持导出与删除；
- 冲突时保留双方版本，不静默覆盖；
- 不同步自备 API Key；
- 托管模型 Key 永远只存在服务端 Secret。

## 认证与风控

普通用户：

- 邮箱验证码；
- Cloudflare Turnstile；
- 验证码 10 分钟失效；
- 每邮箱每小时最多 5 次；
- 每来源 IP 每小时最多 20 次；
- 会话令牌只保存哈希；
- 会话可撤销，默认 30 天失效。

托管模型：

- Beta 默认每月 300 单位；
- 默认每分钟 15 次请求；
- 默认最多 2 台设备；
- 补全、检查、聊天按不同单位计费；
- 超额后明确提示，不自动扣费；
- 日志不记录草稿正文、验证码、令牌或模型 Key。

管理员：

- 生产环境必须通过 Cloudflare Access；
- 使用管理员邮箱白名单；
- 管理操作写入审计日志；
- 本地管理员密钥仅用于开发环境；
- 工单、用户、额度和支付权限后续拆分为不同角色。

## 工单范围

用户可以：

- 新建账号、收费、技术、模型、隐私、建议和其他工单；
- 查看自己的工单；
- 查看客服回复；
- 在未关闭时追加回复。

管理员可以：

- 搜索主题、用户邮箱和工单号；
- 按状态筛选；
- 调整优先级；
- 更新处理状态；
- 回复用户；
- 查看操作审计。

工单正文可能包含个人信息，应在界面中提醒用户不要发送 API Key、密码或敏感邮件正文。

## 生产配置

上线前必须配置：

- 正式 D1 数据库 ID；
- `ACCOUNT_HASH_PEPPER`；
- `TURNSTILE_SECRET_KEY` 和前端站点 Key；
- `RESEND_API_KEY` 或替代邮件服务；
- `AUTH_EMAIL_FROM`；
- `ADMIN_EMAILS`；
- Cloudflare Access 应用与 MFA 策略；
- `REQUIRE_ACCOUNT_AUTH=1`；
- `ENVIRONMENT=production`；
- 模型供应商服务端 Key；
- Worker 与 Durable Object 绑定；
- 正式域名、隐私政策、用户协议和支持邮箱；
- 日志、成本及错误率告警；
- 数据导出、删除、备份和恢复流程。

## 验收标准

后端：

- 用户 A 无法读取、修改或删除用户 B 的工单和数据；
- 未登录请求无法使用托管模型；
- 过期、撤销和冻结会话立即失效；
- 额度超限不会继续调用上游模型；
- 管理员操作全部记录审计；
- 生产环境缺少 Turnstile、邮件或密钥配置时拒绝启动相关功能。

产品：

- 10 位用户成功完成邮箱登录；
- 10 位用户无需配置模型完成第一次补全或检查；
- 一周内至少 5 位用户重复使用；
- 工单能够从提交走到解决或关闭；
- Microsoft Store 获得首批真实评价。
