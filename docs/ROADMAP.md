# WriteMelo roadmap

WriteMelo's current release is a bring-your-own-key English writing coach for non-native English speakers. It reviews writing in context and explains corrections in the learner's preferred language.

The items below are planned directions, not features included in the current release.

## Personal learning loop

- Weekly common errors based only on corrections the learner accepts.
- Writing progress trends using transparent measures such as accepted corrections per 100 words.
- A saved-expression collection for useful or frequently mistaken phrases.
- Before-and-after revision history with explanations in the learner's preferred language.
- Short personal exercises generated from the learner's own correction history.

Learning records should remain isolated by local user profile unless a future account-based sync feature is explicitly enabled. The product should explain what is stored, provide deletion and export controls, and avoid presenting activity counts as proof of language proficiency.

## Broader writing support

The `W` in WriteMelo is intended to support writing beyond English over time. Any additional writing language should be introduced only after its review quality, explanation quality, interface translation, privacy behavior, and store listing have been tested for that market.

## Release principle

The first release stays focused on reliable English writing, native-language explanations, local drafts, and user-provided model access. Future learning and multilingual-writing features will be released incrementally after testing rather than being advertised as available early.
