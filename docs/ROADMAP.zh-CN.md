# WriteMelo 未来规划

WriteMelo 当前版本定位为：面向非英语母语者、提供母语解释的英文写作教练。第一版由用户接入自己的模型服务，应用结合上下文审查英文写作，并使用学习者选择的语言解释修改原因。

以下内容属于未来规划，不是当前版本已经提供的功能。

## 个人学习闭环

- 根据用户实际接受的修改，统计本周常见错误。
- 使用“每百词接受修改数”等透明指标展示写作进步趋势。
- 收藏有用表达和容易写错的表达。
- 保存修改前后对照，以及用户所选语言的解释。
- 根据个人真实修改历史生成短练习。

学习记录默认应继续按本地用户命名空间隔离。只有未来明确启用账号同步时，才考虑上传经过用户授权的数据。产品需要说明保存内容，提供删除与导出能力，并避免把活跃次数包装成英语水平证明。

## 扩展到其他写作语言

WriteMelo 中的 `W` 代表 Write，而不是只代表 English。未来可以支持其他语言写作，但每增加一种写作语言，都需要先验证该语言的审查质量、解释质量、界面翻译、隐私行为和对应市场的商店资料。

## 发布原则

第一版聚焦可靠的英文写作、母语解释、本地草稿和用户自带模型服务。学习激励与多语言写作功能应在完成测试后逐步发布，不提前宣传为当前可用功能。
