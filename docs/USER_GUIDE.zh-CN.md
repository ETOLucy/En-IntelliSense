# 写美了（WriteMelo）使用指南

[English](USER_GUIDE.md)

## 安装与启动

从 [GitHub Releases](https://github.com/ETOLucy/En-IntelliSense/releases/latest) 下载安装版或便携版。通过微软认证后会增加 Microsoft Store 安装入口。

Windows 桌面版启动后直接进入写作界面，用户不需要另外安装 Python。

## 配置自己的 AI 服务

第一版只使用用户自己的兼容模型服务和 API Key。

1. 点击设置按钮，打开 **AI 服务**。
2. 输入模型服务地址，例如 `https://api.example.com`。
3. 输入 API Key，以及该服务实际支持的模型 ID。
4. 根据服务商文档选择 **Chat Completions** 或 **Responses**。
5. 点击 **测试连接**，成功后保存。

自动补全、审查、润色、解释和聊天默认使用同一个模型。API Key 仅保存在这台电脑上，由 Windows 加密保护，并且只会发送到用户配置的模型服务地址。

## 写作

- 选择文体、读者、英语水平、讲解语言、补全模式和语气。
- 在中央编辑器中开始写作。
- 按 `Tab` 接受补全，按 `Esc` 忽略补全。
- 停止输入片刻或点击 **检查**，即可审查当前草稿。
- 使用 **润色**、**解释**、**简化** 前可以先选择文字；未选择时会处理光标所在句子。
- 点击实用短语会替换选中内容或当前句子。

## 草稿与本地文件

草稿和已完成文档保存在当前 Windows 用户的本地应用数据中。第一版不提供云同步。

桌面版可以打开和保存 UTF-8 编码的 `.txt`、`.md`、`.markdown` 文件。使用 **另存为** 可以保留独立副本。如果文件被其他应用修改，WriteMelo 会在覆盖前提示。

## 打开邮件应用

书信或邮件写完后，点击 **完成** 可以复制完整内容并打开 Windows 默认邮件应用。发送前请检查收件人、主题和正文。

## 常见问题

- **AI 服务不可用：** 打开 AI 服务设置并重新测试连接。
- **身份验证失败：** 到所选模型服务商处确认 API Key 是否有效。
- **找不到模型：** 填写服务商实际支持的模型 ID。
- **服务地址错误：** 使用 HTTPS 地址；除非服务商明确要求，否则不要自行添加路径。
- **桌面窗口无法打开：** 安装或修复 Microsoft Edge WebView2 Runtime。
- **本地文件无法打开：** 转换为 UTF-8 编码，并确保文件小于 5 MB。

不要把 API Key 粘贴到 GitHub Issue，也不要提交到代码仓库。
