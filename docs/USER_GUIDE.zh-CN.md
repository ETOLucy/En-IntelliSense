# WriteMelo 使用指南

## 安装

在 GitHub Releases 下载其中一种：

- `WriteMelo-2.0.0-beta.1-Setup-x64.exe`：带安装向导的 Windows 安装包。
- `WriteMelo-2.0.0-beta.1-Portable-x64.exe`：无需安装的便携版。

代码签名证书到位前，beta 为未签名产物，Windows 可能提示未知发布者。请使用 `SHA256SUMS.txt` 核对 SHA-256。

## 写作

启动后直接进入编辑器，文档会自动保存在设备上。

- 在编辑器上方选择邮件、作文或消息。
- 输入至少两个字母即可看到本地补全候选。
- 在左栏新建或切换文档。
- 通过标题控件重命名当前文档。
- 使用“打开”“保存”“另存为”处理 `.txt`、`.text`、`.md`、`.markdown`；从本地打开后，`Ctrl+S` 会写回已授权路径。
- 在写作设置中选择美式/英式英语和学习难度。
- 在标题栏切换简体中文与英文界面。

## 检查与修复

问题会按错误、警告、建议三种级别直接标在正文中。悬浮可查看原因和 Quick Fix；点击“问题”面板条目会聚焦并选中正文范围。修复后会立即重新分析，编辑器边缘会标出含问题的行。

拼写检查使用内置的 49,568 词条英文词表。除了逐个加入个人词典，也可在设置中导入每行一个单词的 `.txt`，或 Hunspell `.dic`。导入词会在本机去重，最多 50,000 个。

“大纲”页展示段落结构和对应文体的提交检查清单。“版本历史”以词级 Diff 和变更统计比较快照与当前正文；预览后才能确认恢复，恢复后可撤销。编辑期间快照去重、至少间隔 30 秒，每篇文档最多保留最新 100 条。

## 可选 AI

AI 默认关闭，可明确选择“关闭”“仅发送问题”或“问题 + 当前全文”。切换模式本身不会联网，只有真正提交问题才调用供应商。浏览器预览版没有配置托管 AI；Windows 应用支持用户自行配置供应商。

## 自备 AI 服务

Windows 应用可以直连 OpenAI、Groq、Together AI、OpenRouter、Ollama 或自定义 OpenAI 兼容接口：

1. 打开右侧“AI”。
2. 选择供应商，并确认接口地址和模型 ID。
3. 远程供应商需要填写 API Key，然后选择“保存供应商”。
4. 选择“仅发送问题”或“问题 + 当前全文”后再提问。

已保存的 Key 使用 Windows `safeStorage` 加密，不会返回给渲染界面。远程供应商会收到经过同意的请求文本，并可能按自身条款收费；WriteMelo 不保证供应商始终提供免费额度。Ollama 可以使用 localhost 接口且不需要 API Key。

## 删除本地数据

浏览器用户可在浏览器设置中清除站点存储。Windows 用户卸载 WriteMelo 后，如需同时删除本地文档和设置，还应删除应用数据目录。清理本地存储前请先导出重要内容。
