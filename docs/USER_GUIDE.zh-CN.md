# WriteMelo 使用指南

## 安装

在 GitHub Releases 下载其中一种：

- `WriteMelo-2.0.0-beta.1-Setup-x64.exe`：带安装向导的 Windows 安装包。
- `WriteMelo-2.0.0-beta.1-Portable-x64.exe`：无需安装的便携版。

代码签名证书到位前，beta 为未签名产物，Windows 可能提示未知发布者。请使用 `SHA256SUMS.txt` 核对 SHA-256。

## 写作

启动后直接进入编辑器，文档会自动保存在设备上。

- 在编辑器上方选择邮件、作文或消息。
- 输入至少两个字母即可看到本地补全候选。
- 在左栏新建或切换文档。
- 在写作设置中选择美式/英式英语和学习难度。
- 在标题栏切换简体中文与英文界面。

## 检查与修复

“问题”页展示本地拼写、语法、措辞、清晰度和重复检查。选择问题后可阅读解释并精确替换；拼写项也可以加入个人词典。

“大纲”页展示段落结构和对应文体的提交检查清单。“版本历史”在本机保存快照，可以恢复早期草稿。

## 可选 AI

AI 默认关闭，关闭时所有本地写作工具仍可使用。启用 AI 必须明确确认；发送整篇文档有单独的勾选项。当前 beta 已建立同意边界，但在区域路由、留存、账号和额度控制配置完成前，不承诺启用生产托管供应商。

## 自备 AI 服务

Windows 应用可以直连 OpenAI、Groq、Together AI、OpenRouter、Ollama 或自定义 OpenAI 兼容接口：

1. 打开右侧“AI”。
2. 选择供应商，并确认接口地址和模型 ID。
3. 远程供应商需要填写 API Key，然后选择“保存供应商”。
4. 明确启用 AI 后再提问；是否发送整篇文档仍然单独选择。

已保存的 Key 使用 Windows `safeStorage` 加密，不会返回给渲染界面。远程供应商会收到经过同意的请求文本，并可能按自身条款收费；WriteMelo 不保证供应商始终提供免费额度。Ollama 可以使用 localhost 接口且不需要 API Key。

## 删除本地数据

浏览器用户可在浏览器设置中清除站点存储。Windows 用户卸载 WriteMelo 后，如需同时删除本地文档和设置，还应删除应用数据目录。清理本地存储前请先导出重要内容。
