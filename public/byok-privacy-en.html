BRING YOUR OWN KEY

Choose an official provider available in your region

A WriteMelo account includes a small hosted trial. Bringing your own key is optional and gives you control over model quality, limits and provider billing.

1Check region and billing→2Create a key with the provider→3Connect it in WriteMelo
Why is a key needed?

The key authorizes API calls on your provider account. A consumer chatbot subscription usually does not include API usage.

Must I pay now?

Not always. Check for explicit free API credit first. If none is offered, start only with the provider's minimum practical amount.

Who handles BYOK billing?

The provider controls charges, balances and refunds for your own key. These charges are separate from WriteMelo plans purchased through Microsoft Store.

REGION AND BILLING

Confirm that your account can use the API before setup

  1. 01
    Check supported countries

    Use the provider's official country list. Do not bypass regional restrictions or identity checks.

  2. 02
    Check free API credit

    Free tiers may expire or restrict models and request volume. Do not assume a chatbot's free plan includes API calls.

  3. 03
    Check payment support

    If billing is required, confirm that your card or payment method is accepted and set a usage limit or alert.

  4. 04
    Create a dedicated key

    Use a separate key for WriteMelo so you can audit usage and revoke it without affecting other projects.

PRIVACY AND COST

The key stays local; necessary text goes directly to the provider

The key is encrypted locally

It is submitted only to the local 127.0.0.1 service and protected with Windows DPAPI for your Windows account.

WriteMelo does not receive the key

Version 01 has no cloud key sync or account backup. Configure the key again on another computer.

The provider receives necessary text

Your computer sends the writing context needed for completion, review or rewriting directly to your selected provider.

The provider may charge you

API calls may be billed by tokens or other usage rules. Pricing, invoices and refunds are controlled by the provider.
