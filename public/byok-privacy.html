模型质量

免费模型能体验流程，更好的模型更适合正式写作

基础模型

适合短补全、简单语法修改和判断软件是否顺手。遇到长文、隐含语气或多轮修改时可能不稳定。

均衡模型

适合日常邮件、课程作业和常规润色。优先比较响应速度、上下文长度和实际输出，不只看价格。

高质量模型

通常更擅长保持全文意图、区分正式与自然语气，并解释复杂修改，适合重要邮件和长文。

先小额测试

同一模型也会受提示、地区和供应商版本影响。先用自己的真实场景比较，再决定是否长期使用。

“更贵”不保证“更好”，但能力更强的模型通常能在复杂任务上提供更稳定的结果。不要为了简单补全盲目选择最高价模型。

工作方式

请求只经过三个位置

1设置界面Key 只提交到 127.0.0.1 本地服务
2Windows 本机使用 DPAPI 绑定当前系统账户加密
3模型供应商本机携带 Key 发出模型请求

WriteMelo 的云端接口会拒绝包含 api_key、apiKey 或 provider_key 的 JSON 请求。

配置步骤

四个字段分别填什么

  1. 打开“套餐与 AI 服务”

    在 Windows 版右上角打开设置，展开“使用我自己的模型服务”。

  2. 填写 API 接口地址

    使用供应商官方兼容地址，例如 DeepSeek 的 https://api.deepseek.com。不要填写控制台网页地址。

  3. 填写 API Key 与模型 ID

    Key 通常以供应商定义的前缀开头；模型 ID 必须与账号已开通的模型完全一致。

  4. 选择协议并测试连接

    大多数国内兼容接口选择 Chat Completions。测试成功后再保存，自动补全可单独选择关闭。

自行验证

不必只相信界面上的承诺

  1. 保存时，浏览器网络面板中的目标应是 127.0.0.1。
  2. 配置文件只应出现 api_key_protected，不应出现明文 Key。
  3. 模型请求应由本机直接连接你填写的供应商域名。
  4. 退出 Windows 账户或复制配置到另一台电脑后，原加密 Key 不应被解密。

重要限制

自备 Key 不等于免费

供应商照常计费

每次补全、润色、检查和对话都会消耗供应商 Token 余额。

供应商会收到文本

为了生成结果，请求内容必须发送给你选择的模型供应商。

Key 无法云同步

这是刻意的安全边界。换设备后需要重新配置。

删除方式明确

在模型设置中清除配置，即可删除本机保存的加密 Key。
