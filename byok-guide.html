自备 API KEY

选择中国大陆可直连的官方 API 平台

WriteMelo 01 版不出售额度、不要求订阅。你直接向模型供应商申请 API Key，并自行决定是否使用免费额度或付费服务。

1确认地区与付款条件→2在官方平台创建 Key→3回到 WriteMelo 配置
为什么需要 API Key？

Key 用来授权你的供应商账户调用模型。聊天产品会员通常不包含 API 用量。

现在必须付费吗？

不一定。先查看供应商是否提供免费额度；没有免费额度时，也只建议从平台允许的最低金额开始。

谁负责收费？

费用、退款和余额都由供应商处理。WriteMelo 不代充、不抽成，也不会自动替你开通付费。

以下推荐面向中文版和中国大陆用户。请从官方开放平台创建 Key，不要把聊天会员、网页地址或来源不明的共享 Key 当作 API 服务。

DeepSeek 开放平台日常英文写作与价格敏感场景api.deepseek.com 阿里云百炼通义千问模型与大陆网络dashscope.aliyuncs.com 智谱 BigModelGLM 模型与中文服务支持open.bigmodel.cn Moonshot 开放平台Kimi 模型与长文本任务api.moonshot.cn

供应商的免费额度、实名要求、可用模型和价格会变化，请以其官方控制台当日显示为准。不要购买来源不明的共享 Key或中转 Key。

地区与付款

注册前先确认账户是否可以正常使用

  1. 01
    确认服务地区

    检查平台是否接受你所在地区注册，以及是否要求中国大陆手机号或实名认证。

  2. 02
    确认免费额度

    免费额度可能有期限、模型限制或请求上限；没有明确赠送时，不要假设一定免费。

  3. 03
    确认付款方式

    需要付费时，先确认平台接受你的付款方式，并设置余额提醒或消费上限。

  4. 04
    创建独立 Key

    为 WriteMelo 单独创建一个 Key，便于随时停用和核对用量。

隐私与费用

Key 留在本机，必要文本直达供应商

Key 在本机加密

Key 只提交给本机 127.0.0.1 服务，并使用 Windows DPAPI 绑定当前 Windows 账户加密保存。

WriteMelo 不接收 Key

01 版没有账号同步或云端 Key 备份。换电脑后需要重新配置。

供应商会收到必要文本

补全、检查或改写时，本机会把完成任务所需的写作上下文直接发送给你选择的供应商。

供应商可能收费

模型调用可能按 Token 或其他规则计费，价格、账单和退款均由供应商决定。
