BRING YOUR OWN KEY

先用免费层试写，再决定模型档位

WriteMelo 不卖充值，也不会催你订阅。优先选择供应商允许的免费 API 层；免费模型适合体验流程，能力更强的模型通常更适合正式邮件和长文。

1注册供应商账户→2领取免费额度并创建 Key→3回到 WriteMelo 配置
为什么要 API Key？

可以把 AI 理解成按用量计费的水电服务：WriteMelo 是你电脑里的工具，真正生成文字的是你选择的 AI 供应商。

一定要立刻付费吗？

不用。先找明确的免费计划或赠送额度；不想花钱时，不要开通自动付费，免费额度用完就停止。

会不会不停扣钱？

不会自动向 WriteMelo 付款。你可以在供应商控制台查看账单、设置限额，余额用完后停止使用。

比较模型

简单任务看速度，复杂任务看能力

免费或基础模型

适合短补全、简单语法修改和体验软件，长文一致性与细微语气可能不稳定。

均衡模型

适合日常邮件和常规润色。优先比较响应速度、上下文长度和你的实际输出。

高质量模型

通常更擅长保持全文意图、正式语气、复杂改写和解释，适合重要邮件与长文。

价格不是能力证明

先用同一段真实文本测试补全、审查和润色，再决定是否值得付费。

选择供应商

优先使用官方 API 平台

不要在聊天产品会员页面购买。网页会员通常不能当作 API 额度使用，应进入供应商的开放平台或模型服务控制台。

DeepSeek 开放平台价格敏感、普通英文写作api.deepseek.com 阿里云百炼中国大陆网络、通义千问模型dashscope.aliyuncs.com 智谱 BigModelGLM 模型和中文任务open.bigmodel.cn Moonshot 开放平台Kimi 模型和长文本api.moonshot.cn

不要购买来源不明的共享 Key。中转服务可能看到 Key、请求内容和返回内容，其价格与稳定性也不受官方保证。

购买步骤

有免费层先用，不想花钱就关闭自动付费

  1. 01
    注册并完成供应商要求的验证

    地区、实名或支付要求以供应商页面为准。

  2. 02
    在 API 控制台开通按量计费

    第一次只充少量余额，并设置余额提醒或消费上限。

  3. 03
    创建一个只给 WriteMelo 使用的 Key

    不要复用重要项目的 Key；创建后立即妥善保存，很多平台只展示一次。

  4. 04
    确认可用模型 ID

    模型名称必须与控制台和供应商文档完全一致。

隐私与费用

Key 留在本机，文本发给供应商

WriteMelo 不接收 Key

Key 只提交到 127.0.0.1，并由 Windows DPAPI 加密保存在当前账户。

供应商会收到写作内容

生成补全、审查或改写时，必要文本会直接从本机发送给所选供应商。

每次调用都会计费

费用按供应商 Token 定价扣除。WriteMelo 不经手充值，也不承诺供应商价格。

Key 不会云同步

换电脑后需要重新配置。删除本地应用数据即可移除已保存的加密 Key。
